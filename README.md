# Agave Frontend

Interface for the Agave protocol on Gnosis Chain.

## Development

Use Node.js 24 (minimum 22.12).

```sh
npm ci
npm start
```

## Verification and release

```sh
npm run typecheck
npm test
npm run build
```

Contract bindings are regenerated by these commands. Vite writes the static
site to `build/` with relative asset URLs; the existing hash routes work on
Vercel and on IPFS gateways. Vercel settings are in `vercel.json`.

## Wallets

The connection picker uses EIP-6963 announcements to select each installed
browser wallet explicitly, prioritizing Rabby and Ambire before MetaMask and
other wallets. WalletConnect v1 and Frame connectors have been removed.
Wallet selection is explicit on each page load. Transactions require the
selected account and Gnosis Chain to remain active, including after approvals.
Wallet labels are self-attested by the extension; install trusted wallets.

## Security scope

The dependency refresh preserves React 17, Chakra 1, and ethers 5 APIs while
replacing Create React App with Vite. Remaining low elliptic advisories in
ethers 5 have no patched compatible release. The app uses external wallet
signers rather than creating private-key wallets.

Vercel supplies frame, content-type, and referrer protections. IPFS gateway
headers depend on the gateway operator. This frontend review does not audit
the deployed contracts or prove transaction behavior on live wallets.
